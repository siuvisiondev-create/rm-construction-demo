# R & M Construction — Private Website Concept

A standalone, non-indexed website concept prepared exclusively for R & M Construction, LLC.

This is an unofficial concept and is not affiliated with or endorsed by R & M Construction, LLC. Project references are based on publicly available information.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

No environment variables are required.

Latest production concept build is deployed through Vercel.
